# 오스키실 예약판

오스키실 1–6번 방 시간표와 실습 재료 10종 × 2세트 대여 현황. 조원은 링크로 보기만, 신청·취소·재료 대여는 조장 코드로 로그인한 조장만.

주소
- 예약판 (조장 신청): `https://osce-board.vercel.app/`
- 현황판 (누구나 보기, 실시간): `https://osce-board.vercel.app/view.html`

Supabase 주소·키는 `config.js` 한 곳에만 있고 두 페이지가 같이 씀.
배포: Vercel이 `main` 브랜치에 push될 때마다 자동 배포 (GitHub Pages는 사용 안 함).

## Supabase 세팅 (dw가 할 일)
1. supabase.com → 프로젝트 열기 (두근두근 치의학부 프로젝트에 같이 넣어도 됨, 테이블 이름 `bookings`·`kits`·`leaders`가 겹치지 않으면 OK)
2. **SQL Editor** → `schema.sql` 위쪽 6)번의 팀 목록 `array['A',...,'H']`을 실제 조에 맞게 고치고 → 전체 **Run**
3. 결과로 나오는 **조 / 조장 코드** 표를 각 조장에게 개인톡으로 전달 (코드는 단톡에 올리지 말 것)
4. **Project Settings → API** 에서 Project URL, `anon public` key 복사 → `config.js`에 넣고 커밋
   - GitHub 웹에서 파일 열고 연필(✏️) 눌러 수정 → Commit changes
   - `service_role` 키는 절대 넣지 말 것

## 권한 구조
| | 조원 (로그인 X) | 조장 (코드 로그인) |
|---|---|---|
| 시간표·재료 현황 보기 | O | O |
| 연습 신청 | X | O (우리 조로만) |
| 신청 취소 | X | 우리 조 신청만 |
| 재료 대여·반납 | X | O |

모든 쓰기는 DB 함수(`create_booking`, `cancel_booking`, `set_kit`)에서 조장 코드를 확인한 뒤에만 됨. `leaders` 테이블은 아무도 직접 못 읽음.

## DB가 막아주는 것
- 같은 날·같은 방·겹치는 시간 → 거부
- 같은 조가 같은 시간에 방 두 개 → 거부 (관리자 대리 신청은 허용)
- 관리자 대리 신청: 끝나는 시간 30분 단위 자유 설정(3시간 넘어도 됨), 방 여러 개 한 번에 선택(방마다 한 건씩, 재료는 남는 세트를 앞 방부터), 신청 후 창이 안 닫히고 다음 빈 방으로 바로 이어서 추가
- 신청 변경: 조장은 시작 전 우리 조 신청만(고정 시간대 제외), 관리자는 전부 — 날짜·시간·방·연습내용·재료(관리자는 조도)
- 같은 재료 세트를 겹치는 시간에 → 거부
- 사용 시간은 1시간 또는 2시간만

## 자주 쓰는 SQL
```sql
-- 조장 코드 재발급 (조장 바뀔 때)
update leaders set code = upper(substr(md5(random()::text),1,6)) where team = 'C';
select team, code from leaders order by team;
-- 조 추가
insert into leaders (team, code) values ('I', upper(substr(md5(random()::text),1,6)));
-- 지난 예약 정리
delete from bookings where date < current_date - 30;
```

## 수정 포인트 (`index.html` 스크립트 맨 위)
`ROOMS`(방), `KITS`(재료), `DURS`(사용 시간), `OPEN`/`CLOSE`(운영 시간). 재료를 추가하면 `kits` 테이블에도 `id` 두 줄(예: `xray-1`, `xray-2`) 추가.

## 업데이트 014: 연습 플랜 (`plan.html`, DB 변경 없음)
- 상단 탭 '연습 플랜'(조장 메뉴에도 버튼) → 조장 코드로 들어감(예약판 로그인 유지). 관리자는 조를 골라서.
- ① 형(A·B·C… 이름·개수 자유, 최대 8) 마다 연습할 질환 입력(쉼표로 여러 개)
- ② 기간 + 케이스당 시험(기본 10분)·피드백(기본 5분)·준비·정리 여유(기본 10분) → 예약 시간에서 여유를 빼고 케이스를 채움(1시간 3케이스, 2시간 7케이스)
- 하루에 형 '섞어서' / '하루 한 형' 선택 + **요일별 형 지정**(예: 월·수 A·B, 화·목 C) + 날짜마다 형 직접 지정 — 우선순위 날짜 → 요일 → 기본 설정
- ③ 기간 안 우리 조 예약을 자동으로 불러옴. 시간은 플랜에서만 조절(예약은 그대로), 빼기·예약 밖 연습 추가 가능
- 질환마다 횟수가 고르게(가장 적게 한 질환 → 같은 시간 안 중복 피함 → 형 번갈아) 배분, 질환별 횟수 표시
- 결과: 이미지 저장·이미지 복사(카톡 붙여넣기)·공유(폰)·글로 복사. 설정은 이 기기에 조별로 저장(localStorage `osce-plan-v1-<조>`)
- ④ 시간대별 형·이름: 조원 명단(쉼표) → 칸마다 돌아가며 자동 배정(가장 적게 맡은 사람, 바로 앞 사람 피함), 칸마다 이름 직접 입력 가능. 예약 시간대마다 형 지정(자동/A/B/C), 칸마다 형 지정도 가능 — 우선순위 칸 → 시간대 → 날짜 → 요일 → 기본 설정. 이미지·글 복사에 이름과 사람별 케이스 수 표시
- 형 목록의 질환은 한 번 넣으면 계속 저장(기기별): 질환 이름을 누르면 이번 플랜에서 빼기/넣기(흐린 테두리 = 빠짐), ✕는 목록에서 지우기(확인 후)
- ④ 칸 순서 바꾸기: ⠿ 손잡이를 잡고 끌어서 옮김(마우스·터치, 키보드는 손잡이에서 ↑↓). 질환·칸 형·이름(자동 이름 포함)이 같이 따라가고 사이 칸은 한 칸씩 밀림. 옮기면 플랜 전체가 그 순서·이름으로 고정(slotItem·namePin) → '전체 자동 배분' 또는 시간대별 '순서 초기화'로 복귀
- ⑤ 지금까지 연습 통계: 시간이 지난 칸은 자동으로 '지난 연습'(hist)으로 확정·저장(그 뒤 설정을 바꿔도 안 바뀜, ③에서 포함을 끄면 빠짐). 질환별·사람별 지난 연습 / 조장 조정(−·+, adjD·adjP) / 합계 / 앞으로(남은 플랜). 앞으로 배분은 합계가 적은 질환·사람부터. 조정 초기화·기록 비우기(비운 시점 전 칸은 다시 안 쌓임). 이미지 칩에 '누적' 표시
- 형 배치 방식 4가지: 번갈아(A·B·C·A…) / 형끼리 묶어서(시간대 안에서 A끼리 → B끼리, 고정·기록·칸 형 지정 없는 시간대만) / 시간대마다 한 형(예약 시간 하나 = 형 하나, 평균 횟수 적은 형부터) / 하루 한 형
